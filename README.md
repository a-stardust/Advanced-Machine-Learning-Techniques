# Advanced Machine Learning Techniques

This repository contains the lab assignments and associated code for the **Advanced Machine Learning Techniques** course (Semester 2). 

The lab programs have been restructured from their original Jupyter Notebook (`.ipynb`) formats into modular, executable Python scripts to promote better software engineering practices and maintainability. The original Jupyter notebooks for each lab are also retained for reference.

## Repository Structure

The labs are organized sequentially into the following directories:

### [1. Introduction to NonLinearity](./1.Introduction_to_NonLinearity/)
Explores non-linear transformations and their impact on machine learning models. 

### [2. Understanding SVM Margins](./2.%20Understanding%20SVM%20Margins/)
Focuses on Support Vector Machines (SVM), examining how margins and support vectors affect classification boundaries.

### [3. SVM on Real and High-Dimensional Data](./3.%20SVM%20on%20Real%20and%20High-Dimensional%20Data/)
Applies SVM algorithms to complex, real-world datasets with high dimensionality, utilizing different kernel tricks.

### [4. Maximum Likelihood Estimation](./4.%20Maximum%20Likelihood%20Estimation/)
Demonstrates parameter estimation using Maximum Likelihood Estimation (MLE) on Bernoulli and Gaussian distributions, alongside sample size convergence plots.

### [5. Gaussian Mixture Models](./5.%20Gaussian%20Mixture%20Models/)
Explores clustering using Gaussian Mixture Models (GMM). Includes a from-scratch implementation of the Expectation-Maximization (EM) algorithm, as well as an applied `scikit-learn` version on a real marketing campaign dataset.

## Setup and Execution
Each directory contains its own `readme.md` detailing the specific scripts, modules, and how to run the code. Ensure you have the required dependencies (such as `numpy`, `matplotlib`, `scikit-learn`, `pandas`, `scipy`) installed in your Python environment before running the scripts.
