# Maximum Likelihood Estimation

This module demonstrates the concept of **Maximum Likelihood Estimation (MLE)**
through analytical and experimental approaches using common probability models.

## Concepts Covered
- Likelihood and log-likelihood functions
- MLE for Gaussian distribution
- MLE for Bernoulli distribution
- Relationship between sample statistics and MLE

## File Overview
- `data.py` – Synthetic data generation
- `likelihood.py` – Likelihood and log-likelihood functions
- `visualization.py` – Likelihood plotting utilities
- `gaussian_mle.py` – Gaussian MLE experiment
- `bernoulli_mle.py` – Bernoulli MLE experiment
- `requirements.txt` – Required dependencies
