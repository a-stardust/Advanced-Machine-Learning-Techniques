# SVM on Real and High-Dimensional Data

This module studies the behavior of Support Vector Machines (SVMs) on real-world
and large-scale synthetic datasets.

## Experiments Covered
- Linear vs Polynomial SVM on the Breast Cancer dataset
- SVM performance on high-sample, high-dimensional synthetic data
- Comparison of accuracy, number of support vectors, and training time

## File Overview
- `data.py` – Dataset loading and generation
- `preprocessing.py` – Train-test split and feature scaling
- `breast_cancer_svm.py` – Real-world dataset analysis
- `high_dimensional_svm.py` – Large-scale synthetic data experiment
- `requirements.txt` – Required dependencies
